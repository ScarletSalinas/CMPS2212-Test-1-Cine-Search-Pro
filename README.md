# CMPS2212 GUI Programming
## Test #1: Cine-Search Pro - Movie Search Dashboard

### Test Description
Build a production-grade movie search dashboard using Vanilla JS and Raw CSS. Demonstrate mastery over asynchronous data fetching, DOM performance, and state management. Implement debounced search, request cancellation, concurrent data fetching with resilience, result caching, keyboard navigation, and XSS-safe text highlighting using the TMDB API.

## 📂 Project Structure

```text
.
├── index.html         # Main application structure with templates
├── style.css          # Responsive grid layout, movie details, trailer cards
├── script.js          # SearchComponent class with all features
└── README.md          # Project documentation
```
